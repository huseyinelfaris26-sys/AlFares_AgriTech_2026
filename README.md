# JaziraAgri-OS

نظام مفتوح المصدر للزراعة الذكية يعمل بدون إنترنت، يركز على:

- مراقبة رطوبة التربة
- تحليل ملوحة التربة
- إدارة الري
- تنبؤات المحاصيل
- لوحة تحكم إقليمية

## التشغيل

```bash
npm install
npm start
```

ثم افتح المتصفح على:

```text
http://localhost:3000
```

## المكونات

- Node.js + Express
- واجهة مستخدم عربية متجاوبة
- بيانات تجريبية للإقليم السوري
- واجهات API جاهزة للتوسيع
