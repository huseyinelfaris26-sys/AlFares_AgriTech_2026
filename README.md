# JaziraAgri-OS

منصة تجريبية عربية لمتابعة مؤشرات زراعية في الجزيرة السورية. تتضمن لوحة متجاوبة، واجهات API محلية، بحثًا في الحقول، ودعمًا أساسيًا للعمل دون اتصال بعد أول زيارة.

> **تنبيه:** كل الأرقام والطقس والتنبيهات في النسخة الحالية بيانات تجريبية ثابتة، وليست قياسات حية أو توصيات مهنية. لا تستخدمها للتحكم بالري أو لاتخاذ قرارات زراعية. يلزم ربط حساسات موثوقة ومصادر طقس معتمدة والتحقق الميداني قبل الاستخدام التشغيلي.

## التشغيل

يتطلب Node.js 18 أو أحدث.

```bash
npm install
npm start
```

ثم افتح http://localhost:3000. للتطوير مع إعادة تشغيل تلقائية استخدم `npm run dev`.

## الميزات الحالية

- واجهة RTL عربية متجاوبة مع تنقل وروابط للأقسام.
- بحث فوري عن الحقول حسب الاسم أو المنطقة أو المعرّف.
- تحديث بيانات مع رسائل حالة وأخطاء واضحة.
- دعم PWA وذاكرة مؤقتة للواجهة وواجهات API للعمل دون اتصال بعد تحميلها مرة واحدة.
- رؤوس أمان أساسية واستجابة 404 بصيغة JSON لمسارات API غير المعروفة.

## واجهات API

`GET /api/overview`, `/api/regions`, `/api/fields`, `/api/alerts`, `/api/forecast`, `/api/system`.

## الخطوات التالية للإنتاج

استبدال بيانات العرض بقاعدة بيانات ومصادر حساسات/طقس موثوقة، إضافة مصادقة وصلاحيات ونسخ احتياطي واختبارات ومراقبة، ثم مراجعة أمنية وميدانية. لا توجد حاليًا مصادقة أو قاعدة بيانات أو تكامل حقيقي مع Sentinel-2 أو LoRa.
